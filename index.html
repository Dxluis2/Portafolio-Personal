Desarrollo Web

Agenda Escolar PWA

Aplicación Web Progresiva (PWA) desarrollada para facilitar la organización académica de estudiantes. Cuenta con un panel de control que permite visualizar materias registradas, tareas pendientes, actividades completadas y próximas fechas de entrega. Integra administración de materias, calendario, gestión de tareas y recordatorios mediante notificaciones. Utiliza React, TypeScript y Firebase para ofrecer una experiencia moderna y accesible desde el navegador.
